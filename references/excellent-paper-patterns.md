# 优秀论文的可迁移模式

按 [model-type-playbooks.md](model-type-playbooks.md) 识别主/辅助类型后，只读下方同类小节。三认知 Pass（ARCHITECT/SKEPTIC/REVIEWER）以 [route-iteration.md](route-iteration.md) 为准；本文件提供具体的选择、攻击和修正动作，并在末节沉淀 Modeling Decision Pattern Library。

> 下方各题型小节的 **首轮 / 风险轮 / 修订轮 / 失败后** 分别对应 **PASS 1 ARCHITECT / PASS 2 SKEPTIC / PASS 3 REVIEWER / 证伪后的修法**；标签沿用旧名，实质以 route-iteration.md 的三 Pass 为准。

## 经验等级与证据

来源定位见 [excellent-paper-evidence.md](excellent-paper-evidence.md)：L01—L22 是用户论文包中的文件与 PDF 物理页码，用于内部复查，不是实战参考文献。

- **重复经验**：至少两篇已查看正文出现同一种做法，注明是否仅同题复现。可优先尝试，不证明该方法导致获奖或适用一切问题。
- **案例经验**：只在单篇或特殊条件看到的机制，先测试前提，不升格成共同 Gate。
- **补充建议**：审查提出的验证/修正动作，不声称样本论文都执行过。下述风险轮、修订轮和失败后动作均属补充建议，除非另有定位。
- 抽取乱码、摘要宣称或未复核运行的结论不作为数学真值；来源台账和 numeric provenance 继续独立执行。

## 优化、运筹、调度、资源配置

**重复经验（跨题）**：工程限制落实到算法输出并讨论计算成本。L06 的贪心/回溯承认目标次序影响次要指标；L14 测实时耗时并讨论学习策略越限和安全修正；L07 检验运输容量扰动。

- **首轮**：变量可控且有目标/约束时使用。建立现行规则或可行贪心，独立复算容量/时序/供需，依据规模、可行率和预算选择精确、分解或启发式方法。
- **风险轮**：攻击紧约束、冲突需求、极端容量和目标顺序；预测输入还需检查偏差后的实际可行性。
- **修订轮**：修复/投影后重新计算目标与约束，分别报告训练、推理与修复时间。下界可得时算 Gap，不可得时注明未知，基线差距不等于最优性 Gap。
- **失败后**：不可行先定位冲突约束；超时采用缩小搜索/热启动；偏科重审优先次序。风机专用指标与特定安全层仅为 L14 案例，不照搬到排班。

## 统计、回归、预测、时间序列

**重复经验（跨年跨题）**：按跨度、对象和工况分解预测，再对照旧方法与观测。L02 按跨度/污染物建子模型并承认局部负改进；L18 按交通密度分析模型失效，明确特征与未来目标的对应。

- **首轮**：定义“何时用当时可见信息预测什么”。有一次预测时可试误差校正，否则先做持续性/季节性/线性基线；残差或分组差异支持时再加复杂模块。
- **风险轮**：先按独立事件/患者/站点或时间划分，再在训练折内拟合插补、缩放、特征筛选和调参；滑窗不能跨分区共享目标/未来信息。分组/时间隔离优先于普通随机分层。
- **修订轮**：分跨度、极端事件与稀少群体报误差，在相同数据预算下比较模型；区分参数估计、选模与最终测试，拟合优度不代替泛化。
- **失败后**：平均改善而关键群体变差，可分工况建模或回退基线并验证切换规则；样本少则减少分组/复杂度。L02 的具体污染物与站点结论仅为案例。

## 分类、聚类、机器学习、数据挖掘

**重复经验（跨年跨题）**：可解释特征与候选模型对照。L04 比较特征重要性方法和回归基线；L22 比较波形特征与简单分类器；L13 比较降水模型效果和计算量。

- **首轮**：有标签先确认标签时间和类别分布，简单模型可分就不必加深网。无标签走聚类分支，以距离/尺度、簇数和业务解释建基线，不强求分类准确率。
- **风险轮**：分类查少数类漏判、阈值、重复实体与泄漏；聚类查尺度、初始化、簇数与重采样稳定性。特征重要性只说明预测关联。
- **修订轮**：分类根据适用的 PR/ROC、混淆矩阵、校准和错误样本修订；聚类结合内部结构、稳定性与领域解释，外部标签可用时再加外部一致性。
- **案例与失败后**：L02 承认直接指定簇数的局限，迁移的是簇数选择检查；L22 满分指标仍讨论样本易分，应补查泄漏和外部难例，不宣称完美泛化。

## 机理、微分/差分方程、动力系统

**重复经验（跨题）**：基础系统逐步增加机制，用外部参照或内部不变量验证。L03 先核对单神经元曲线，承认复杂回路/效果指标局限；L19 核对坐标转换的能量、角动量；L16 比较原模型与工况修正。

- **首轮**：列量纲、状态、驱动、初边值、可观测量和参数来源。参数估计需审可辨识性，不能把互相补偿的一组拟合参数都解释为真实物理量。
- **风险轮**：做步长/求解器、边界、守恒、极限和参数扰动，区分模型形式错误与数值误差。无外部观测时不能把数值稳定写成实际验证完成。
- **修订轮**：先修单位/实现再改机理，保留校准外数据，报告参数不确定性。
- **案例与失败后（L16）**：多求解器结果相近而跨工况误差仍在，随后改模型关系；可迁移的是“换算法无收益时检查结构”，不是所有机理模型都加温度项。守恒也不能发现所有旋转方向错误，需额外已知姿态/解析参照。

## 随机过程、Monte Carlo、系统仿真

**重复经验（跨题）**：解析模型与事件仿真/观测轮廓对照。L08 做参数场景的理论—仿真对照并承认某协议未实现；L19 构造到达过程及轮廓对照。未据此认定这些论文均做过多种子或置信区间。

- **首轮**：明确随机机制、分布来源、事件时钟、观测口径和简化/解析参照，先测基本事件再组合系统。
- **风险轮**：独立重复、延长时长和改变步长/种子，区分采样波动、初始过渡与实现偏差；相关样本有效样本量不能当作总采样数。
- **修订轮**：按精度决定重复数，报告区间与收敛；均值掩盖尾部时加分位数/失效概率。模型与仿真共用错误假设时，二者吻合不足以证明真实性。
- **失败后**：均值偏差不随重复减小，查事件顺序/率函数/热身期后再修模型；未实现的机制不能靠其它场景通过而宣称已验证。

## 综合评价、多指标决策、排序

**重复经验（同题复现，迁移待验）**：L10、L20 都诊断评分差异、构造修正并对照题目给的共识排名；L20 改变融合权重观察排名。L21 使用离散度赋权只支持该案例采用此法，不支持它普遍客观最优。

- **首轮**：明确对象、方向、缺失值、尺度及重复指标，以等权/现行规则作基线。偏好、可靠性或离散度赋权的含义分别说明。
- **风险轮**：查排名反转、阈值附近对象和指标删改；调参用的共识排名不能再冒充独立验证集。没有真值时报告偏好条件下排序。
- **修订轮**：输出稳定对象、易反转对象及原因；熵权可能放大噪声，应结合测量可靠性。改权重后重算全部对象。
- **失败后**：极敏感则给分层/区间/多情景建议；压小分数极差不必然改善公平，需回到题意的公平定义。

## 图论、网络、路径、空间建模

**重复经验（跨题，分支不同）**：L08 区分互听与干扰关系；L17 对齐异构地理数据；L02 用距离/风向表达空间关系。先定义关系与尺度，不是所有空间问题都转最短路。

- **首轮**：图问题明确节点/边/方向/容量/关系类型；空间场明确投影/栅格/时间聚合/重采样。分别选路径或几何/邻域基线。
- **风险轮**：图做断边/容量/权重扰动；空间做跨区留出、配准/分辨率检查，相邻像素随机划分不能说明跨区泛化。
- **修订轮**：路径可行、定位误差或残差地图与任务约束对账，查边界/稀疏区；多种关系必要时分别建模。
- **失败后**：尺度变化异常先修配准/单位；稀疏区失效则限定区域或补机制。L05 仅片段复核，不升级为通用算法推荐。

## 数学构造、理论分析、数值计算

**重复经验（相关矩阵题，非全部理论题）**：L01 分开比较结构利用与计算步骤成本；L09 分开讨论误差目标、尺度参数与硬件成本。迁移的是口径清楚，不能推广为所有题都有同一层数下界。

- **首轮**：构造题明确命题、定义域和必要/充分条件；近似计算用精确/高精度参照，依据相关性/稀疏/谱结构决定适用性。
- **风险轮**：反例、边界、病态输入与命题对应；复杂度区分运算次数、共享、存储和实测时间，实验不能补全证明。
- **修订轮**：需要最优性时区分各目标的下界；纯存在性/恒等式不强求最优。近似题另查有限精度、收敛和容差。
- **失败后**：下界不可达先查条件/对象/口径；结构弱化使近似失效则降低近似程度或回退精确法。FFT 等旧题结构仅条件调用。

## Hybrid 综合题

**重复经验（跨题）**：L04 将特征/预测接到候选筛选；L16 衔接分类、工况拟合与决策；L18 从观测提取到预测与交通策略。围绕共同业务输出组织小问，不按算法名拼章节。

- **首轮**：写模块输入输出、单位、可见时间和不确定性，各建简单基线；改一个模块时固定其它模块作对照。
- **风险轮**：扰动上游输出，核验下游排名/可行性/收益，查重复预处理与跨问泄漏；预测分数改善未必改善决策。
- **修订轮**：消融与端到端测试；代理模型优化出的极端方案由原机理/真实约束复算，超出训练支持域则加约束、补数据或回退。
- **失败后**：先定位输入、模块或接口，再决定联合求解或解耦；不把单题的模型串联变成所有综合题的固定路线。

## 条件性辅标签

**时空数据**：L02、L13、L17、L18 支持对齐的价值；时间滚动、事件/地域隔离和极端误差检查是补充建议。L13 的随机划分文字不足以独自证明窗口无泄漏，须检查实际边界。

**因果推断**：L21 用未干预模型轨迹作对照只是案例，不等于因果已识别。题目要求效应且识别假设可说明时启用；混杂、同期干预和安慰剂检查为补充建议。时空数据、预测精度和重要性不自动产生因果结论。

**新标签**：不能覆盖时按扩充卡暂记 Hybrid/待定，先验证完整任务，再积累多篇/多题支持；不把单篇技巧设为永久要求。

## Modeling Decision Pattern Library（建模决策模式库）

上面各节是**题型验证卡**；本节是**决策模式库**——沉淀优秀论文在 Phase C（见 [excellent-paper-learning.md](excellent-paper-learning.md)）中反复出现、可定位、跨题的**建模决策**，形式是“**结构信号 → 表示/路线决策 → 验证 → 证据等级 + 来源定位**”。它回答“看到这种结构，优秀队伍怎么决定表示与路线”，而不是“这类题怎么验证”。

条目模板（每条都必须可定位到来源页码，否则降级为“补充建议”）：

```text
- 触发（结构信号）：题目呈现何种结构/信息/约束时
- 决策（表示或路线）：优秀论文选择了什么表示/抽象/路线，放弃了什么
- 为什么（结构契合）：该决策如何贴合结构（回扣“更好的表示 > 更高级的算法”）
- 验证（Gate/区分实验）：用什么证据确认这个决策成立
- 证据等级：重复经验(≥2篇可定位) / 案例经验(单篇) / 补充建议(审查提出)
- 来源定位：L##，PDF 物理页码
```

已沉淀的决策模式（示例，随实际阅读增补；**不得**把单篇技巧写成永久规则）：

- **触发**：预测/统计题且信息有明确时间或实体截止时刻 → **决策**：先定义“何时用当时可见信息预测什么”，按事件/患者/站点或时间划分而非随机分层 → **为什么**：泄漏会伪装成高精度，划分方式由信息结构决定 → **验证**：训练折内完成插补/缩放/选特征/调参，留出期或跨区评估 → **证据等级**：重复经验 → **来源**：L02、L13、L17、L18。
- **触发**：评价/排序题无客观真值 → **决策**：以等权或现行规则为基线，赋权方式（偏好/可靠性/离散度）各自说明含义，输出“稳定对象 + 易反转对象 + 原因” → **为什么**：权重是价值判断，排名稳定性才是可验证对象 → **验证**：权重/标准化/缺失值扰动下的排名反转分析；调参用的共识排名不再冒充独立验证集 → **证据等级**：同题复现（迁移待验）→ **来源**：L10、L20、L21。
- **触发**：机理题出现“多求解器结果相近但跨工况误差仍在” → **决策**：判定为**模型形式**问题而非数值误差，改的是机理关系不是算法 → **为什么**：换算法无收益即指向结构错误 → **验证**：保留校准外数据，报告参数不确定性 → **证据等级**：案例经验 → **来源**：L16。
- **触发**：矩阵分解/构造题主张“最优” → **决策**：区分**层数下界**与**运算成本下界**为不同命题，分别证明；置换可吸收进稀疏因子；共享运算需题面授权 → **为什么**：口径不清会把“一个下界”误当成“另一个下界” → **验证**：构造达到所证下界 + 独立程序核验有限实例 → **证据等级**：相关矩阵题（非全部理论题）→ **来源**：L01、L09。

维护纪律：库里的每条都服务于**当前题的决策**，不是历年答案目录；只在识别为对应结构信号时调用；新条目必须先有可定位来源，再标经验等级。抽取乱码、只见摘要宣称或未复核运行的结论**不入库**。
