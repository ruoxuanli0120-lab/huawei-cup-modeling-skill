# Optional plugin routing

Use built-in project files, web research, and document rendering first. Plugins and math-modeling are optional; absent plugins are not a workflow failure. External accounts require the user's connection and explicit scope.

- **SciSpace (preferred):** literature discovery, paper reading, and method triangulation. Verify every selected source against publisher/DOI/official metadata before it enters the literature registry or `参考文献`.
- **Consensus (alternative):** quickly screens empirical research claims. It is useful for applied-model background, but not as proof for a mathematical theorem or an algorithmic lower bound.
- **Sider Scholar (alternative):** assists with paper discovery and reading when the user already has a literature collection.
- **Wolfram:** optional independent symbolic or numerical cross-check for difficult derivations. Report it as a cross-check, not as evidence replacing derivation, data, or reproducible code.

This team does not use shared-cloud delivery or a defense-deck workflow. Do not add them by default. Do not install, connect, upload, or share through a plugin without user authorization. Do not use a plugin to write references from unverified snippets or to continue past `PAUSED_FOR_CAPTAIN`.
