# 从优秀论文学习而不照抄

跨年份的可迁移经验见 [references/excellent-paper-patterns.md](excellent-paper-patterns.md)。本文件负责来源边界、抽样纪律和当前题的调用方式；不要把它扩写成历年答案目录。

本文件的 Phase A/B/C 是**历史资产分级加载**在文献上的特例（一般规则见 [competition-execution.md](competition-execution.md)）：infrastructure assets（parser/schema/legality checker/evaluator/fixture）可早用；solution assets（历史 solver、启发式、参数、历史结果、往届建模路线、优秀论文的具体路线）必须在独立完成题意理解与自有路线竞争之后才进入比较。目标是防 solution anchoring，不是重复造基础设施。

## 调用时机：A 独立分析 → B 自有路线 → C 论文当挑战者

优秀论文是**灵感来源与挑战者**，不是**答案模板**。**禁止**一上来就翻优秀论文套结构——那会把别人的表示强加到本题，扼杀对本题结构的独立洞察。正确时机：

- **Phase A · 独立分析**：先只读本题，独立完成 UNDERSTAND（[Problem Insight Map](../templates/problem-audit.md)：数学本质、结构、信息结构、小问依赖、表示备选、核心洞察）。此阶段**不打开**优秀论文。
- **Phase B · 自有洞察与路线**：基于 A 的洞察，自己用 [model-ideation.md](model-ideation.md) 以 4–6 条结构路线为探索目标并竞争出主线+挑战者；若更多路线只是凑数则停止。此时你已有**自己的**判断。
- **Phase C · 论文当挑战者/灵感源**：**这之后**才读同类优秀论文，用法是：
  1. 把你的路线与论文路线**对撞**——论文是否用了你没想到的**表示**或**结构判断**？若是，作为挑战者重新进锦标赛，而不是直接照搬。
  2. 只迁移**可迁移的机制**（如何拆题、如何选模型的证据、如何验证与设边界、如何把数值写进摘要），不复制标题/段落/图形/具体结论。
  3. 把反复出现、可定位、跨题的判断沉淀进 **Modeling Decision Pattern Library**（见 [excellent-paper-patterns.md](excellent-paper-patterns.md) 末节），标注经验等级与来源页码。

判据：若你无法先说出**自己**对本题的核心洞察与主线，就不该进入 Phase C。论文永远用来**挑战/丰富**你的路线，不用来**替代**它。

当用户提供优秀论文时，抽样范围和已读页码必须记录。不要声称解压等于通读，也不把奖项身份当成数学正确性的保证。

提取可迁移的写作机制：背景如何引出目标；各问输入输出如何衔接；选择模型的证据；基线比较与边界测试；摘要如何报告实际数值；图表如何形成论据。把这些机制应用到当前题，而不是复制标题、段落和图形。

按当前题型核对容易被排版掩盖的错误：预测/分类的验证泄漏、机理的量纲和可辨识性、仿真的随机误差、评价的权重与排名稳定性、空间数据的配准、构造的归一化/计数/证明范围。参考文献中的结论要追溯原文，不能把二手转述当证明。

公开存档可能含实名封面、目录和超长附录，不据此推定匿名提交格式、必须目录或官方页数上限。当前年份的正式通知优先。

创新点区分三类：本题中的新建模判断、相对基线的可验证改进、需要完整文献检索才能声称的研究新颖性。不能把已有FFT结构、一般投影或常规调参包装成世界首次；可以准确报告本题的结构取舍、边界发现和有效改进。

对矩阵分解/数学构造类题可迁移的教训：层数下界与运算成本下界是不同命题；置换可吸收到稀疏因子；共享运算需题面授权或显式因子构造；不同小问不能偷渡约束；原题退化解与工程非退化分支必须分开。该经验只在识别为相应类型时调用，不作为预测、统计、仿真或评价题的默认路线。

题型的验证重点和调用方式统一见 [model-type-playbooks.md](model-type-playbooks.md)。经验等级必须区分：多篇不同论文可定位支持的重复做法、单篇案例、由审查补充的建议。重复出现只增加迁移价值，不证明数学正确或因该做法获奖；同一题的多支队伍不等于跨问题验证。缺少原文页码、抽取乱码或只见摘要宣称时，不升格为稳定经验。
