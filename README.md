# Huawei Cup Mathematical Modeling Skill

An AI Agent Skill designed for mathematical modeling competitions, with a focus on the Huawei Cup / China Postgraduate Mathematical Contest in Modeling.

The project provides a structured workflow for problem analysis, mathematical model selection, implementation, validation, and paper review.

## Features

- Competition problem analysis
- Mathematical modeling strategy generation
- Model selection and comparison
- Python implementation assistance
- Data analysis workflow
- Model validation and error checking
- Mathematical modeling paper structure review
- Result consistency checking
- Reproducible modeling workflow

## Use Cases

This project is designed for students participating in mathematical modeling competitions, including:

- Huawei Cup / China Postgraduate Mathematical Contest in Modeling
- CUMCM
- MCM / ICM
- Other university-level mathematical modeling competitions
